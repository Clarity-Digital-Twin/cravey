# BUG-031: Timestamp Picker Not Centered

**Priority:** P4 (Polish)
**Status:** OPEN
**File:** `Cravey/Presentation/Views/Components/TimestampPicker.swift`
**Reported:** 2026-01-27

## Problem

The "When did this happen?" timestamp picker displays with left-aligned date/time pills that look unbalanced. The date and time buttons should be centered for better visual symmetry.

## Screenshot

![Timestamp Picker](../assets/timestamp-picker-left-aligned.png)

Current: `[Jan 27, 2026] [10:02 AM]` aligned left
Expected: `[Jan 27, 2026] [10:02 AM]` centered

## Fix

Update `TimestampPicker.swift` to center the date picker elements:

```swift
struct TimestampPicker: View {
    @Binding var date: Date

    var body: some View {
        VStack(alignment: .center, spacing: 8) {  // Center alignment
            Text("When did this happen?")
                .font(.subheadline)
                .foregroundStyle(.secondary)

            DatePicker(
                "",  // Empty label (we use our own Text above)
                selection: $date,
                in: ...Date(),
                displayedComponents: [.date, .hourAndMinute]
            )
            .labelsHidden()  // Hide the built-in label
            .datePickerStyle(.compact)
        }
        .frame(maxWidth: .infinity)  // Take full width for centering
    }
}
```
