# BUG-026: Craving Timestamp Shows Awkward Format

**Status:** FIXED
**Priority:** P2
**File:** `Cravey/Presentation/Views/Craving/CravingListView.swift:91`

## Problem

Craving rows show timestamps like "55 min, 37 sec" which is overly precise and awkward.

## Current Code

```swift
Text(craving.timestamp.formatted(date: .abbreviated, time: .shortened))
```

## Expected

Show "Today at 6:30 PM" or "Jan 26 at 6:30 PM" like UsageListView does.

## Fix

Use `.formatted(date: .abbreviated, time: .shortened)` or create a `TimestampFormatter` utility.

✅ Implemented by matching the Usage list timestamp format.
