# BUG-030: MessageMapper Silent Enum Downgrade

**Status:** OPEN
**Priority:** P3
**File:** `Cravey/Data/Mappers/MessageMapper.swift:25-46`

## Problem

`MessageMapper.toEntity(_:)` silently downgrades an unrecognized `category` string to `.urge`. This can misclassify data (and hides schema drift), especially when reading older/newer persisted data.

## Current Code

```swift
if let parsed = MessageCategory(rawValue: model.category) {
    category = parsed
} else {
    logger.warning("Invalid category ... defaulting to .urge")
    category = .urge
}
```

## Expected

Unknown persisted values should not be silently reclassified as a different category.

## Fix

Prefer forward-compatible handling:
- Add `.unknown` to `MessageCategory`, and map invalid strings to `.unknown`.
- Optionally expose `.unknown` as “Other/Unknown” in any future UI, but keep it out of normal user selection lists.
