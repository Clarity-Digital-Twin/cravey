# BUG-025: HomeView Sheet Success Race Condition

**Status:** CLOSED
**Priority:** P2
**File:** `Cravey/Presentation/Views/Home/HomeView.swift:58-77`

## Problem

This issue is no longer reproducible with the current implementation:
- The form dismisses on `didSucceed` via `.onChange(of: viewModel.didSucceed)`.
- `HomeView` captures `didSucceed` before clearing the sheet ViewModel in the sheet’s `onDismiss`.

## Current Code

```swift
.sheet(isPresented: $showCravingLogSheet) {
    let didSucceed = cravingLogViewModel?.didSucceed ?? false
    cravingLogViewModel = nil
    // ...
    if didSucceed { /* toast */ }
}
```

## Expected

Success toast should always appear when a craving is logged successfully.

## Fix

Already implemented: the sheet dismisses on `didSucceed` changes in `CravingLogForm`, and `HomeView` reads `didSucceed` before clearing the ViewModel.
