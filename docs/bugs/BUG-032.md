# BUG-032: Trigger Chips Layout Could Be Better Organized

**Priority:** P4 (Polish)
**Status:** OPEN
**File:** `Cravey/Presentation/Views/Components/ChipSelector.swift`
**Reported:** 2026-01-27

## Problem

The trigger chips ("Hungry", "Angry", "Anxious", "Lonely", etc.) and location chips wrap naturally based on available space, but the visual grouping could be improved for better readability.

Current layout (auto-wrap):
```
[Hungry] [Angry] [Anxious] [Lonely]
[Tired] [Sad] [Bored] [Social] [Habit]
[Paraphernalia]
```

The HAALT acronym (Hungry, Angry, Anxious, Lonely, Tired) is a clinical concept that groups naturally. Consider whether a more intentional arrangement improves UX.

## Options

### Option A: Keep Current (Auto-Wrap)
✅ Adapts to all screen sizes automatically
✅ No hardcoded layout
❌ HAALT grouping is split

### Option B: Explicit Row Grouping
Group by clinical concept:
- Row 1: HAALT triggers (Hungry, Angry, Anxious, Lonely, Tired)
- Row 2: Emotional (Sad, Bored)
- Row 3: Contextual (Social, Habit, Paraphernalia)

### Option C: Alphabetical
More predictable for users who know what they're looking for.

## Decision

**Defer to User Testing** - The current auto-wrap is functional. Revisit if user feedback indicates confusion.

## Acceptance Criteria

- [ ] User testing determines if layout changes are needed
- [ ] If changed, maintain ≥44pt tap targets (Apple HIG)
- [ ] Works on iPhone SE through iPad Pro
