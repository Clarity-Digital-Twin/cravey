# BUG-027: Delete All Data Not Atomic

**Status:** OPEN
**Priority:** P2
**File:** `Cravey/Data/UseCases/SwiftDataDeleteAllUserDataUseCase.swift:16-30`

## Problem

File deletion and database deletion are separate operations. If file deletion fails, database deletion still proceeds, creating orphaned records.

## Current Code

```swift
// Step 1: Delete files (may fail)
try await Task.detached(...) { try FileStorageManager.deleteAllRecordings() }.value

// Step 2: Delete database (proceeds even if Step 1 failed)
try await MainActor.run { ... }
```

## Expected

Either all data is deleted, or errors are handled gracefully.

## Fix

Delete database first, then files best-effort. Database integrity is more important than disk cleanup.
