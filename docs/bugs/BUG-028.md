# BUG-028: RecordingMapper Silent Enum Downgrade

**Status:** OPEN
**Priority:** P3
**File:** `Cravey/Data/Mappers/RecordingMapper.swift:28-45`

## Problem

Invalid enum values are silently converted to defaults (`.audio`, `.motivational`) with only a warning log, causing silent data loss.

## Current Code

```swift
if let parsed = RecordingType(rawValue: model.type) {
    recordingType = parsed
} else {
    logger.warning("Invalid recording type...")
    recordingType = .audio  // Silent downgrade
}
```

## Expected

Handle invalid enums gracefully without data loss.

## Fix

Add `.unknown` case to enums for forward compatibility with schema migrations.
