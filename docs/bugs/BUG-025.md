# BUG-025: HomeView Sheet Success Race Condition

**Status:** OPEN
**Priority:** P2
**File:** `Cravey/Presentation/Views/Home/HomeView.swift:58-77`

## Problem

In the sheet's onDismiss closure, `didSucceed` is read but the ViewModel may already be deallocated, causing the success toast to not appear reliably.

## Current Code

```swift
.sheet(isPresented: $showCravingLogSheet) {
    let didSucceed = cravingLogViewModel?.didSucceed ?? false
    cravingLogViewModel = nil
    // ...
    if didSucceed { /* toast */ }
}
```

## Expected

Success toast should always appear when a craving is logged successfully.

## Fix

Use `onChange(of:)` to detect success before dismissal.
